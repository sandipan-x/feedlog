# FeedLog

Free newborn feeding tracker: one-tap feed and diaper log, live time-since-last-feed timer, 24-hour summary and CSV export. No signup.

## Features
- One-tap feed/diaper quick-log with a live time-since-last-feed timer
- 24-hour summary of feeds, wet/dirty diapers and bottle totals against typical ranges
- Day history timeline with one-click CSV export for the pediatrician
